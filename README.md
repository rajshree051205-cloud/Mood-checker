📌 Age & Mood Checker

A simple and interactive web application that allows users to check their age and analyze their current mood in a fun and engaging way. Built using HTML, CSS, and JavaScript, this project focuses on clean design and smooth user experience.

🚀 Features

🎂 Enter your age easily

😊 Select your current mood (Happy, etc.)

⚡ Instant result on button click

🎨 Clean, minimal, and responsive UI

💡 Beginner-friendly project
